# 睡眠參數分頁

依使用者提供的「睡眠平台數據定義_20261020_yc.docx」新增，放在 Dashboard 的「睡眠分析」後。所有計算為顯示用途，不修改原始紀錄、資料庫結構或既有研究公式。

| 參數 | 本頁定義 | 單位／來源 |
| --- | --- | --- |
| 總躺床時數 | 離床－躺床 | 分鐘／日誌 |
| 整體入睡時間 TST | 最後醒來－入睡 | 分鐘／日誌醒來、手錶入睡 |
| 睡眠潛伏期 SOL | 入睡－躺床 | 分鐘／手錶入睡、日誌躺床 |
| 夜間醒來次數 | 個案填寫次數 | 次／日誌 |
| 入睡後醒來時間 WASO | 手錶提供的清醒時間 | 分鐘／手錶 awake_minutes 或 DocterCloud data.awake |
| 睡眠效率 SE | 本頁 TST／總躺床時數 × 100 | % |
| 賴床時間 | 離床－最後醒來 | 分鐘／日誌 |
| 入睡前平均壓力指數 | 入睡前時窗內實際有效量測的算術平均 | 依來源量尺 |
| 入睡前平均疲倦指數 | 同上 | 依來源量尺 |

此處 TST 是文件指定的經過時間，沒有扣除清醒；SOL 從躺床開始；WASO 是來源清醒摘要。既有「睡眠分析」仍使用原研究定義（確認分期的 TST、開始嘗試入睡的 SOL、完整時間軸內的 WASO），兩者不可直接當成相同指標。

日期皆為台灣醒來日期。時刻使用 Asia/Taipei，可跨午夜；舊日誌須確認 wake_date 才自動配對。日期或受試者不符、時間順序錯誤、超過 24 小時、不唯一的紀錄皆不自動計算跨來源值。同日多筆分列，可在單次觀察明確選擇。真實 0 保留；缺值顯示「—」與原因，不補零、不插值。

預設採來源已確認的 sleep_onset_at。若平台只有開放結尾的分期起點，使用者可勾選「採用首筆睡眠分期起點供觀察」；系統僅採已觀察到的淺睡／深睡／REM 起點，逐筆標明來源，不推估分期終點、不更動原研究值。無效的來源入睡時間不以其他時刻覆蓋。

入睡前時窗預設 60 分鐘，可選 30／120；範圍為 `[入睡時間－時窗, 入睡時間)`。壓力／疲倦保留有限的負數與零，排除缺值、NaN、無限值、布林值。依來源、裝置、訊號、演算法版本、單位與量尺分組，分別呈現平均、筆數及首末量測日期時間，不將不同系列混平均。

為涵蓋查詢首日跨夜時窗，只針對壓力、疲倦補讀查詢開始前兩天資料。Supabase 使用既有 caller JWT、受試者限制與 RLS，僅 SELECT；DocterCloud 的 HRV 讀取延伸兩天，額外資料另存 pre_sleep_context，不混入原日期範圍的趨勢或原始匯出。部分載入失敗會提示重新載入。沒有新增寫入或同步動作。

期間對照提供逐筆表格、每筆皆有日期的單一參數長條圖，以及含缺值原因、定義版本、時窗與來源的 CSV；各系列的入睡前指數另有明細 CSV。CSV 文字欄位防止試算表公式注入。Word 原檔不納入公開儲存庫。

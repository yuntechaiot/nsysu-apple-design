# DocterCloud 整合 Dashboard

在正式網站開啟「研究資料」，使用現有日誌帳號登入。登入成功後，伺服器會以本次輸入的帳密連接同一份平台文件所列的 DocterCloud 研究帳號；不用另外開啟 DocterCloud 網站。平台密碼不寫入 Git、Supabase 或應用程式設定，只保留目前工作階段需要的平台 access token。

選擇受試者與日期，按「查看資料」。日誌與已匯入研究資料仍由 Supabase RLS 控管；DocterCloud 資料在這次查詢直接讀取，不會因為查看而備份進 Supabase。日誌帳號每次讀取與自動更新前，皆核對當前 staff 狀態；權限被收回時清除快取及平台連線。

## 可查看的資料

先開啟「健康總覽」查看所選期間的最新心率、同次血壓、血氧、體溫、睡眠時長、SDNN、壓力與疲倦；每張卡片標示量測時間。點卡片可直接開啟對應的「生理數據」類別，切換趨勢圖／量測表，下載中文欄位 CSV。睡眠分析以中文解釋 TST、SOL、WASO、SE；研究比較保留雙軸及標準化進階分析。

睡眠分析依日期選擇紀錄，提供「睡眠圖／睡眠紀錄表」：主區顯示與 DocterCloud 一致的睡眠總時數（淺睡＋深睡＋REM）、深睡、淺睡、REM、清醒時間、階段分布與睡眠時段的心率／血氧；可下載期間內全部睡眠 CSV，同日多筆不覆蓋。WASO、SOL、SE 與日誌對照放在進階研究區。平台 awake 為整段清醒時間，不能在分期起訖不足時直接代替研究 WASO。

最新值、較前次變化及期間統計僅採相同指標、來源、裝置、單位、訊號及演算法版本。收縮壓與舒張壓必須為同次量測才配成血壓卡片；不同時間／原始 ID／來源不湊成一組。未知單位不補猜、缺值不補零，壓力與疲倦不推定正常範圍。

「原始資料／下載」列出 V5-4 文件的 18 類：睡眠、HRV、心率、血壓、血氧、體溫、膽固醇、尿酸、排尿量、飲水量、體重、血糖／醣類分析、心臟與血管健康指數、運動、活動、步數、卡路里、RRI。受試者平台資料與每類全部原始欄位亦可在同一頁查看、分頁與下載 JSON。

平台實際回應可能是完整陣列或分頁物件；程式會依真實回應逐頁讀取到結束，核對 total／current_page，不會把第一頁當成全部。跨三個月查詢自動切為最多 89 天的區段，保留交界紀錄並以來源 ID 去重。單筆格式無法繪圖時，原始紀錄仍可查看；未定義的單位、訊號來源或健康指數量尺不自行補猜。

每類狀態分為「已讀取且有資料」「查詢成功但無紀錄」「讀取未完成」。上游 404、權限、過期登入、參數與分頁異常不會顯示成零筆。2026-10-20 已驗證 18 類可查詢；文件中的 `/back-end/app/physiologic/sports` 回傳 404，因此運動類別使用現行官方入口設定及 Sports 頁面證實的 `/back-end/web/physiologic/sports`。只在該 GET 路由使用相同已授權 access token，不擴充登入、寫入或任意 API 代理能力。

## 對應與範圍

文件所列的研究會員為 ycc 編號，目前平台三組管理帳號各可查詢 50 位。實際平台要求非空 keyword，因此會員清單以文件中的 ycc 前綴查詢，完整走完分頁。自行在日誌網站新增的編號不會假設已在 DocterCloud 存在。

會員以編號與已核對的平台 ID 對應，不用姓名猜測。重複編號／ID 衝突不會混入另一位受試者的日誌；平台額外會員仍可獨立查看。既有與即時平台指標按來源、原始 ID、指標與絕對時間合併，避免不同時區文字造成重複圖表。

原有單獨的「手錶平台」登入及手動研究匯入保留，供帳密日後分開或平台暫時無法連線時使用。查看資料的流程不會自動匯入或寫入研究資料庫。

# UI 分析與設計變更

## 原 UI 的觀察

- 主功能完整，但首頁、管理入口與說明文字的視覺權重接近。
- 手機仍有日期／時間雙欄與緊密的評分控制，長文字壓縮可操作空間。
- 按壓缺少即時回饋；畫面沒有依系統動態、透明度偏好提供替代呈現。
- 日誌與 Streamlit Dashboard 使用不同顏色與卡片語彙。

## 對應 Apple Fluid Interface

1. Purpose／Simplicity：優先顯示日誌與研究兩個任務；管理與歷史入口完整保留。
2. Typography：平台系統字體，大標題收緊字距，內文增加行距，間距用 rem。
3. Flexibility：手機單欄、足夠觸控範圍，保留原生日期選擇與 24 小時文字輸入。
4. Response：pointerdown 開始縮放；原生 click／表單仍直接執行，不加入等待時間。
5. Interruptibility：Spring 從當前 scale 與 velocity 重新設定目標，快速重複按壓不跳位。
6. Behavior：解析臨界阻尼 Spring，response 0.32 秒、damping ratio 1；沒有手勢動量時不加入彈跳。
7. Materials：頁首與表單操作區使用霧面層，內容卡片用實色維持可讀性。
8. Accessibility：保留焦點、語義標籤及鍵盤行為；減少動態時禁用 Spring；減少透明度／高對比使用實色。

## 功能邊界

日誌、歷史、管理、邀請、搜尋、驗證與 cloud transport 的原始 JavaScript 檔完全沿用；Python 的資料查詢、公式、匯入與平台整合不變。新增 CSS、獨立互動回饋檔、Dashboard 樣式載入與頁面文案。沒有新增第三方前端 CDN 或追蹤。沒有替換原網站的部署或 remote。

## 折線圖可讀性

- 健康總覽、生理資料、進階比較、壓力／疲倦及睡眠趨勢統一用較大的繪圖區、淡網格與精簡日期標籤。跨年期間顯示年份，完整日期時間保留於點按提示。
- 同一指標維持固定色彩，搭配線型區分系列；名稱與單位分開，來源、裝置、訊號與版本在提示內保留。圖例可單獨隱藏／顯示系列。
- 手機預設不攔截圖內拖動；開啟「縮放工具」後可框選放大、拖動日期範圍、重設及下載。
- 原始值、研究公式與資料來源不改。明確缺值保留斷線；不補零、不平滑。不同演算法版本不接成同一條線；同時刻多筆標準化觀察各自保留原始值。
- Y 軸仍依資料自動縮放，應依實際刻度判讀變化；不添加未經來源定義的健康範圍或好壞判定。

驗證：82 個 Python 測試、Ruff、Mypy 通過；`tools/verify_chart_ui.py` 使用標示為合成資料的獨立預覽，檢查 320／390／768／1365px 排版、手機點按提示、缺值斷線、圖例切換及選用縮放工具。預覽及截圖只存於受忽略的 test-results，不部署合成研究紀錄。

## 依觀察目的選圖

健康總覽、生理數據與壓力／疲倦加入「建議呈現／原始點位／每日範圍／折線圖」。量測表、匯出、縮放與進階雙軸／標準化比較保留。建議呈現不修改查詢或資料，只選擇圖形：

| 觀察目的／資料 | 建議呈現 | 理由 |
| --- | --- | --- |
| 零星或單日量測 | 實際時間點圖 | 不暗示兩次量測之間有連續資訊 |
| 多日且每天重複量測 | 每日中位數＋最低／最高範圍 | 同時觀察中心位置與日內變化，避免密集折線堆疊 |
| 同次血壓 | 收縮壓／舒張壓配對點 | 看見每次的兩個值；只連接無歧義的同次量測 |
| 睡眠時長 | 每筆紀錄長條 | 從零起算、以小時顯示；同日多筆分開，不自行加總 |
| 步數等語意未確認的累積計數 | 原始點位 | 不將計數器擅自加總成每日總量 |

每日範圍的自動判斷是介面規則：同一來源／裝置／訊號／版本至少三個有紀錄日、十二筆有效觀察，且至少三日各有兩筆以上。這不是統計有效性或醫療判定；使用者可隨時切換。中位數與範圍只依已查詢的紀錄計算，不代表完整全天，也不是正常範圍。日期使用台灣時間，缺少的日期不補零。不同單位不可共用每日範圍軸；不同系列不合併計算。

驗證：89 個 Python 測試、Ruff、Mypy 通過；`tools/verify_observation_ui.py` 驗證 320／390／768／1365px 排版、每日範圍點按提示、原始點位／折線切換、同次血壓配對與未提供睡眠時長的標示。合成資料與比較截圖僅在本機 test-results/observations，不部署到研究資料庫。

## 完整日期標籤

所有趨勢圖明確列出每個有量測紀錄的日期，不使用自動跳日刻度。睡眠長條保留每一筆紀錄的日期與同日筆次；跨年加上年份。八個日期／紀錄以上使用足夠的繪圖寬度及圖表內橫向捲動，手機不必省略日期，也不撐寬整頁。量測時間仍可點按查看。驗證增加六日全標、跨年與缺值日期標籤，以及手機十四日完整標籤／橫向捲動；91 個 Python 測試通過。
